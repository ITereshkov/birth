# Avito AI Copilot (онлайн-репетиторы)

Практический стартовый репозиторий для сборки AI-копилота, который помогает:
- анализировать объявления и метрики;
- рекомендовать ставки и бюджет;
- улучшать заголовки и тексты;
- планировать действия на день/неделю.

## Быстрый запуск

1. Поднимите PostgreSQL (локально или в контейнере).
2. Задайте `DATABASE_URL`:

```bash
export DATABASE_URL="postgresql://avito:avito@localhost:5432/avito_copilot"
```

3. Примените миграции:

```bash
./scripts/run_migrations.sh
```

4. Проверка ETL-заглушки:

```bash
python src/etl/run_daily_etl.py
```

## Логика первой рекомендации по ставке

В `src/optimizer/bid_rules.py` реализовано MVP-правило:
- если доля в топе падает 2+ дня подряд;
- и CPL в целевом диапазоне;
- повысить ставку на 10%.

См. файл `DATA_REQUEST.md`.
