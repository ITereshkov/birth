# Данные, которые нужны от вас для следующего этапа

Чтобы я реализовал полноценный ETL и первые рекомендации по ставке/бюджету, пришлите:

1. Экспорт по вашим объявлениям за 14-30 дней (CSV/Excel):
   - `ad_id`
   - дата
   - показы
   - просмотры
   - контакты
   - избранное
   - расход
   - ставка (если есть)

2. Справочник объявлений:
   - `ad_id`, предмет, регион, текущий заголовок, цена

3. Целевые бизнес-ограничения:
   - целевой CPL по сегментам
   - дневной/месячный лимит бюджета
   - минимальное число контактов в неделю

4. (Опционально) Список конкурентов:
   - ссылки/ID конкурентов по регионам и предметам

После получения этих данных я смогу:
- подключить загрузку в БД;
- рассчитать KPI по каждому объявлению;
- выдать первые авто-рекомендации по ставке и бюджету.
